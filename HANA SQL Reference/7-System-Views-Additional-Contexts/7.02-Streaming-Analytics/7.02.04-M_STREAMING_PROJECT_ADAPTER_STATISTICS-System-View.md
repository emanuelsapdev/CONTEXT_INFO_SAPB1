# 7.2.4 M_STREAMING_PROJECT_ADAPTER_STATISTICS System View [Streaming Analytics]

> [↑ 7.2 Streaming Analytics](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 2181–2182

Contains custom statistics for both external and internal adapters.

Only users with a MONITOR role can view the content of this system view. The view is empty for all other users.

## Structure

| **Column name** | **Data type** | **Unit** | **Description** |
| --- | --- | --- | --- |
| SCHEMA_NAME | NVARCHAR(256) |   | The schema in which the project is deployed. |
| PROJECT_NAME | NVARCHAR(256) |   | The name given to the project. It corresponds to the APPLICATION_NAME in the M_STREAMING_APPLICATIONS System View for APPLICATION_TYPE "PROJECT" or "HA_PROJECT". |
| PROJECT_INSTANCE | INTEGER |   | The instance number of the project.. It corresponds to the APPLICATION_INSTANCE in the M_STREAMING_APPLICATIONS System View for APPLICATION_TYPE "PROJECT" or "HA_PROJECT". |
| ADAPTER_NAME | NVARCHAR(256) |   | Unique name of the adapter instance. |
| STATISTICS_NAME | NVARCHAR(256) |   | The name of an adapter statistic, as defined by the adapter. |
| STATISTICS_VALUE | NVARCHAR(256) |   | The value of the statistic (converted to a string). |
| LAST_UPDATE_TIME | TIMESTAMP |   | The last time the statistic was updated for the adapter. |

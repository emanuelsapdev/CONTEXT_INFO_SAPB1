# 7.2 Streaming Analytics

> [↑ 7 System Views Reference for Additional SAP HANA Contexts](../README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 2174–2175

> **Caution**
>
> This guide contains syntax variations for different product contexts. These are handled as separate reference topics that have titles that announce the context in square brackets at the end of the title. The guide is also organized to keep reference topics together for a context. Always be sure you are using the SQL reference topic specific to your context.

M_STREAMING_APPLICATIONS System View [Streaming Analytics] [→](7.02.01-M_STREAMING_APPLICATIONS-System-View-Streaming-Analytics.md)

Provides a list of streaming analytics applications running in the SAP HANA streaming analytics cluster.

M_STREAMING_PROJECTS System View [Streaming Analytics] [→](7.02.02-M_STREAMING_PROJECTS-System-View-Streaming-Analytics.md)

Provides information and statistics about each streaming analytics project deployed in the SAP HANA streaming analytics cluster.

M_STREAMING_PROJECT_ADAPTERS System View [Streaming Analytics] [→](7.02.03-M_STREAMING_PROJECT_ADAPTERS-System-View-Streaming-Analytics.md)

Contains information about internal adapters attached to each SAP HANA streaming analytics project

M_STREAMING_PROJECT_ADAPTER_STATISTICS System View [Streaming Analytics] [→](7.02.04-M_STREAMING_PROJECT_ADAPTER_STATISTICS-System-View.md)

Contains custom statistics for both external and internal adapters.

M_STREAMING_PROJECT_GD_SUBSCRIPTIONS System View [Streaming Analytics] [→](7.02.05-M_STREAMING_PROJECT_GD_SUBSCRIPTIONS-System-View-Streaming.md)

Contains information about active and inactive GD (Guaranteed Delivery) Subscriptions. The subscribers can be either external subscribers or internal adapters that support GD.

M_STREAMING_PROJECT_PUBLISHERS System View [Streaming Analytics] [→](7.02.06-M_STREAMING_PROJECT_PUBLISHERS-System-View-Streaming.md)

Contains information and statistics about streaming publishers for each SAP HANA streaming analytics project, including external adapters.

M_STREAMING_PROJECT_SUBSCRIBERS System View [Streaming Analytics] [→](7.02.07-M_STREAMING_PROJECT_SUBSCRIBERS-System-View-Streaming.md)

Contains information and statistics about streaming subscribers for each SAP HANA streaming analytics project, including external adapters.

M_STREAMING_PROJECT_STREAMS System View [Streaming Analytics] [→](7.02.08-M_STREAMING_PROJECT_STREAMS-System-View-Streaming-Analytics.md)

Provides information and statistics about each stream in an SAP HANA streaming analytics project.

M_STREAMING_SCHEMAS System View [Streaming Analytics] [→](7.02.09-M_STREAMING_SCHEMAS-System-View-Streaming-Analytics.md)

Provides a list of the streaming schemas in the SAP HANA streaming analytics cluster

M_STREAMING_SERVICES System View [Streaming Analytics] [→](7.02.10-M_STREAMING_SERVICES-System-View-Streaming-Analytics.md)

Provides a list of logical node names in the SAP HANA streaming analytics cluster.

[Additional Views For Streaming Analytics](7.02.11-Additional-Views-For-Streaming-Analytics.md)

Views including information pertaining to, but not limited to, SAP HANA streaming analytics.

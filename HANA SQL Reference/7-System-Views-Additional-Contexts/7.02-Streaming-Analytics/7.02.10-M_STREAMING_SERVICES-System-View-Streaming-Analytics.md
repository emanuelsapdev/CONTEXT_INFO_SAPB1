# 7.2.10 M_STREAMING_SERVICES System View [Streaming Analytics]

> [↑ 7.2 Streaming Analytics](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, página 2192

Provides a list of logical node names in the SAP HANA streaming analytics cluster.

Only users with a MONITOR role can view the content of this system view. The view is empty for all other users.

## Structure

| **Column name** | **Data type** | **Unit** | **Description** |
| --- | --- | --- | --- |
| SERVICE_ALIAS | NVARCHAR(256) |   | Name of the streaming node. |
| HOST | VARCHAR(64) |   | Streaming node host. |
| PORT | INTEGER |   | Streaming node port. |

# 7.2.9 M_STREAMING_SCHEMAS System View [Streaming Analytics]

> [↑ 7.2 Streaming Analytics](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 2191–2192

Provides a list of the streaming schemas in the SAP HANA streaming analytics cluster

Only users with a MONITOR role can view the content of this system view. The view is empty for all other users.

## Structure

| **Column name** | **Data type** | **Unit** | **Description** |
| --- | --- | --- | --- |
| SCHEMA_NAME | NVARCHAR(256) |   | The name of the schema where the streaming applications are deployed. |

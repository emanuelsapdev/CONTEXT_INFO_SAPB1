# 7.1.3 M_ES_DBSPACES System View [Dynamic Tiering]

> [↑ 7.1 Dynamic Tiering](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 2164–2165

Shows the dbspace configured in extended storage.

System and user data for the extended storage is managed in dbspaces, which can contain one or more files. This monitoring view provides information for the extended storage corresponding to the connected HANA database.

Only users with CATALOG READ, DATA ADMIN, or EXTENDED STORAGE ADMIN system privilege can view the content of the M_ES_DBSPACES view. The view is empty for all other database users.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| HOST | VARCHAR(64) | Host name. |
| PORT | INTEGER | Internal port. |
| VOLUME_ID | INTEGER | Volume ID. |
| DBSPACE_NAME | VARCHAR(128) | Name of the dbspace. |
| TYPE | VARCHAR(11) | Type of the dbspace:<br>• MAIN<br>• TEMPORARY<br>• SHARED_TEMP<br>• RLV<br>• CACHE<br>• CATALOG |
| STATUS | VARCHAR(7) | Status of the dbspace:<br>• OFFLINE<br>• ONLINE |
| MODE | VARCHAR(9) | Mode of the dbspace:<br>• READONLY<br>• READWRITE |
| USAGE | DOUBLE | Percent of dbspace in use. |
| TOTAL_SIZE | BIGINT | Total size of the dbspace in bytes. |
| RESERVED_SIZE | BIGINT | Total reserved space in bytes that can be added to dbfiles in the dbspace. |
| FILE_COUNT | INTEGER | Total number of files in the dbspace. |
| READWRITE_FILE_COUNT | INTEGER | Total number of read-write files in the dbspace. |
| IS_DISK_STRIPING_ENABLED | VARCHAR(5) | TRUE if disk striping is enabled for the dbspace, else FALSE. |
| DISK_STRIPE_SIZE | BIGINT | Disk stripe size in byte. |

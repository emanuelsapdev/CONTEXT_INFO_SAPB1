# 7.1.9 M_ES_RESULT_CACHE [Dynamic Tiering]

> [↑ 7.1 Dynamic Tiering](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 2169–2170

Status information on the result cache storage for SAP HANA dynamic tiering.

Only users with EXTENDED STORAGE ADMIN system privilege can view the content of the M_ES_RESULT_CACHE view. The view is empty for all other database users.

There is one row for each result in the result cache.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| SCHEMA_NAME | NVARCHAR(256) | The schema name. |
| TABLE_NAME | NVARCHAR(256) | The name of the table. |
| COLUMNS | NCLOB | The columns included in the result as a comma separated list. |
| PREDICATES | NCLOB | The predicates used to generate the result as a comma separated list. |
| COMMIT_ID | BIGINT | The version number of the table. |
| STATEMENT_STRING | NCLOB | The query that generated the result. |
| CREATE_TIME | TIMESTAMP | The timestamp the result cache entry is generated and stored. |
| CREATE_DURATION | BIGINT | The number of milliseconds it took to generate the original result. |
| CREATE_CONNECTION_ID | BIGINT | The connection ID that generated the result. This connection id can join the REMOTE_CONNECTION_ID of M_REMOTE_STATEMENTS. |
| LAST_ACCESS_TIME | TIMESTAMP | The last time the result cache entry was accessed by a user. |
| LAST_CONNECTION_ID | BIGINT | The last connection ID that accessed the result. This connection id can join the REMOTE_CONNECTION_ID of M_REMOTE_STATEMENTS. |
| HIT_COUNT | BIGINT | The number of accesses on the cache entry. |
| SUBSET_HIT_COUNT | BIGINT | The number of accesses on the cache entry that only used a subset of the result. |
| EXACT_MATCH_HIT_COUNT | BIGINT | The number of accesses on the cache entry that used the whole result. |
| RESULT_SIZE | BIGINT | The size of memory occupied by the result cache entry (in bytes). |

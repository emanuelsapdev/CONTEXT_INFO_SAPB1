# 7.1.6 M_ES_EXPENSIVE_STATEMENTS System View [Dynamic Tiering]

> [↑ 7.1 Dynamic Tiering](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, página 2167

Provides an interface to give system administrators more visibility into where time and resources are being spent during statement executions that involve extended storage. The information is a result of the union of M_EXPENSIVE_STATEMENTS and M_REMOTE_STATEMENTS.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| CONNECTION_ID | INTEGER | Connection ID. |
| TRANSACTION_ID | INTEGER | Transaction ID. |
| STATEMENT_ID | VARCHAR(20) | Statement ID. |
| OPERATION | NVARCHAR(5000) | Type of operation (such as prepare, execute, fetch, close). |
| START_TIME | TIMESTAMP | Statement start time. |
| DURATION_MICROSEC | BIGINT | Statement duration. |
| STATEMENT_STRING | NCLOB | Statement string. |
| RECORDS | BIGINT | Number of records. |

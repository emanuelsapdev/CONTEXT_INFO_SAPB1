# 7.1.8 M_ES_OVERVIEW System View [Dynamic Tiering]

> [↑ 7.1 Dynamic Tiering](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 2168–2169

Status information of SAP HANA dynamic tiering as named value pair.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| CATEGORY | VARCHAR(32) | Describes the main category type for which the parameters and values are shown. The following categories are reported:<br>• GENERAL<br>• BUFFERS<br>• MEMORY<br>• STORAGE<br>• DELTA<br>• BACKUP<br>• VERSIONING |
| NAME | VARCHAR(255) | Name of the parameter of which the information is provided in value column. |
| VALUE | VARCHAR(255) | Value of the parameter. |

# 5.4 Text Mining

> [↑ 5 SQL Reference for Additional SAP HANA Contexts](../README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1379–1380

> **Caution**
>
> This guide contains syntax variations for different product contexts. These are handled as separate reference topics that have titles that announce the context in square brackets at the end of the title. The guide is also organized to keep reference topics together for a context. Always be sure you are using the SQL reference topic specific to your context.

[Text Mining: TM_CATEGORIZE_KNN Function](5.04.01-Text-Mining-TM_CATEGORIZE_KNN-Function.md)

This function classifies (categorizes) an input document with respect to sets of categories (taxonomies).

[Text Mining: TM_GET_RELATED_DOCUMENTS Function](5.04.02-Text-Mining-TM_GET_RELATED_DOCUMENTS-Function.md)

This text mining function returns the top-ranked related documents for a query document within a search request and stores these documents (including metadata) in the return table.

[Text Mining: TM_GET_RELATED_TERMS Function](5.04.03-Text-Mining-TM_GET_RELATED_TERMS-Function.md)

This text mining function returns the top-ranked related terms for a query term, based on a set of reference documents.

[Text Mining: TM_GET_RELEVANT_DOCUMENTS Function](5.04.04-Text-Mining-TM_GET_RELEVANT_DOCUMENTS-Function.md)

This text mining function returns the top-ranked documents that are relevant to a term.

[Text Mining: TM_GET_RELEVANT_TERMS Function](5.04.05-Text-Mining-TM_GET_RELEVANT_TERMS-Function.md)

This text mining function returns the top-ranked relevant terms that describe a document.

[Text Mining: TM_GET_SUGGESTED_TERMS Function](5.04.06-Text-Mining-TM_GET_SUGGESTED_TERMS-Function.md)

This text mining function returns the top-ranked terms that match an initial substring. This function can be used for type-ahead or auto-completion functions.

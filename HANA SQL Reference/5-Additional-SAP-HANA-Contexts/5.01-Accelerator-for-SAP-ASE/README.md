# 5.1 Accelerator for SAP ASE

> [↑ 5 SQL Reference for Additional SAP HANA Contexts](../README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1207–1208

> **Caution**
>
> This guide contains syntax variations for different product contexts. These are handled as separate reference topics that have titles that announce the context in square brackets at the end of the title. The guide is also organized to keep reference topics together for a context. Always be sure you are using the SQL reference topic specific to your context.

ALTER DATABASE Statement [Accelerator for SAP ASE] [→](5.01.01-ALTER-DATABASE-Statement-Accelerator-for-SAP-ASE.md)

Alters an existing database by adding or removing the `etsserver` service.

ALTER SYSTEM ALTER CONFIGURATION Statement [Accelerator for SAP ASE] [→](5.01.02-ALTER-SYSTEM-ALTER-CONFIGURATION-Statement-Accelerator-for.md)

Enables the accelerator for SAP ASE service for provisioning to a tenant database.

ALTER SYSTEM INITIALIZE SERVICE Statement [Accelerator for SAP ASE] [→](5.01.03-ALTER-SYSTEM-INITIALIZE-SERVICE-Statement-Accelerator-for.md)

Creates the remote sources and virtual tables, and imports the delivery unit (DU) for the `etsservice` service.

ALTER SYSTEM UNINITIALIZE SERVICE Statement [Accelerator for SAP ASE] [→](5.01.04-ALTER-SYSTEM-UNINITIALIZE-SERVICE-Statement-Accelerator-for.md)

Removes the remote sources, virtual tables, and the delivery unit (DU) for the `etsserver` service.

# 5.1.4 ALTER SYSTEM UNINITIALIZE SERVICE Statement [Accelerator for SAP ASE]

> [↑ 5.1 Accelerator for SAP ASE](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1212–1213

Removes the remote sources, virtual tables, and the delivery unit (DU) for the `etsserver` service.

## Syntax

```sql
ALTER SYSTEM UNINITIALIZE SERVICE 'etsserver'
   [ AT [ LOCATION] <hostname>:<port> ]
   [ <drop_option> ]
```

## Syntax Elements

**hostname** Specifies the name of the dedicated accelerator for SAP ASE host. **port** Specifies the port number where the accelerator for SAP ASE service runs. Port is comprised of 3xx21, where xx is the instance number.

#### drop_option

Drops the `etsserver` service.

```sql
<drop_option> ::= CASCADE | RESTRICT
```

**CASCADE** Drops the extended service and any dependent objects.

##### RESTRICT

Drops the extended service only when dependent objects do not exist.

## Permissions

You must have the SERVICE ADMIN privilege.

## Description

This statement drops the remote sources, virtual tables, and the delivery unit (DU) for the service.

## Examples

The following code example drops the remote sources `etsserver` and dependent objects.

```sql
ALTER SYSTEM UNINITIALIZE SERVICE 'etsserver' drop cascade;
```

# 4 SQL Reference

> Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 25–26

[Introduction to SQL](4.01-Introduction-to-SQL.md)

This chapter describes the SAP HANA database implementation of Structured Query Language (SQL).

[SQL Notation Conventions](4.02-SQL-Notation-Conventions.md)

SQL syntax notation conventions used in this guide.

[Data Types](4.03-Data-Types/README.md)

A data type defines the characteristics of a data value. A special value of NULL is included in every data type to indicate the absence of a value.

[Reserved Words](4.04-Reserved-Words.md)

Reserved words are words which have a special meaning to the SQL parser in the SAP HANA database and cannot be used as when defining an identifier.

[Operators](4.05-Operators.md)

Use operators to perform arithmetic operations in expressions. Operators can be used for calculation, value comparison, or to assign values.

[Expressions](4.06-Expressions.md)

An expression is a clause that can be evaluated to return values.

[SQL Statements](4.10-SQL-Statements/README.md)

SAP HANA supports many SQL statements to allow you to perform such tasks as create database objects, administer your system, and manipulate data.

[System Limitations](4.11-System-Limitations.md)

Limitations to take into consideration when administering an SAP HANA database.

[SQL Error Codes](4.12-SQL-Error-Codes.md)

Each SAP HANA error has a numeric error code. The M_ERROR_CODES system view contains information about the error codes.

# 4.10.1.91 DROP GRAPH WORKSPACE Statement (Data Definition)

> [↑ 4.10.1 Alphabetical List of Statements](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 904–905

Drops a graph workspace.

## Syntax

```sql
DROP GRAPH WORKSPACE <workspace_name>
```

## Syntax Elements

#### workspace_name

Drops the specified graph workspace.

```sql
<workspace_name> ::= [<schema_name>.]<identifier>
```

## Description

Drops a graph workspace.

# 4.10.1.19.35 ALTER SYSTEM MIGRATE ABSTRACT SQL PLAN (System Management)

> [↑ 4.10.1.19 ALTER SYSTEM ... (All ALTER SYSTEM Statements)](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 523–524

Migrates abstract SQL plans to a new SAP HANA system.

## Syntax

```sql
ALTER SYSTEM MIGRATE ABSTRACT SQL PLAN
```

## Description

Execute this statement after you complete a system upgrade.

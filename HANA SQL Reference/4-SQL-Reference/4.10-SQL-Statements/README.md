# 4.10 SQL Statements

> [↑ 4 SQL Reference](../README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 415–416

SAP HANA supports many SQL statements to allow you to perform such tasks as create database objects, administer your system, and manipulate data.

[Alphabetical List of Statements](4.10.01-Statements-A-Z/README.md)

[Access Control Statements](4.10.02-Access-Control-Statements.md)

Access control statements enable database administrators to create, alter, and drop access to the SAP HANA database.

[Backup and Recovery Statements](4.10.03-Backup-and-Recovery-Statements.md)

These statements allow users to perform backup and recovery operations.

[Data Definition Statements](4.10.04-Data-Definition-Statements.md)

Data definition statements define structures in the SAP HANA database.

[Data Import Export Statements](4.10.05-Data-Import-Export-Statements.md)

The following statements import and export data to and from the SAP HANA database.

[Data Manipulation Statements](4.10.06-Data-Manipulation-Statements.md)

The following statements enable you to manipulate data within the SAP HANA database.

[Client-side Encryption Statements](4.10.07-Client-side-Encryption-Statements.md)

Client-side encryption statements enable database administrators to administer client-side encrypted data in the SAP HANA database.

[JSON Document Store Statements](4.10.08-JSON-Document-Store-Statements.md)

There are several JSON Document Storespecific variants of common DDL and DML SQL statements.

[Procedural Statements](4.10.09-Procedural-Statements.md)

Procedural statements manage system and userdefined procedures for the SAP HANA database.

[Session Management Statements](4.10.10-Session-Management-Statements.md)

The following SQL statements manage database sessions.

[System Management Statements](4.10.11-System-Management-Statements.md)

The following statements enable you to manage system configuration settings in your SAP HANA database.

[Tenant Database Management Statements](4.10.12-Tenant-Database-Management-Statements.md)

The following SQL statements manage SAP HANA tenant databases.

[Transaction Management Statements](4.10.13-Transaction-Management-Statements.md)

The following SQL statements manage transactions in the SAP HANA database.

[Workload Management Statements](4.10.14-Workload-Management-Statements.md)

The following SQL statements manage workload classes and mappings.

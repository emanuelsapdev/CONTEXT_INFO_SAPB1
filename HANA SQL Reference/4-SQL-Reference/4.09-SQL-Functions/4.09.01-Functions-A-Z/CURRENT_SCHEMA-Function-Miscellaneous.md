# 4.9.1.55 CURRENT_SCHEMA Function (Miscellaneous)

> [↑ 4.9.1 Alphabetical List Of Functions](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, página 165

Returns a string containing the current schema name.

## Syntax

```sql
CURRENT_SCHEMA
```

## Description

Returns a string containing the current schema name.

## Example

The following example returns the current schema name:

```sql
SELECT CURRENT_SCHEMA "current schema" FROM DUMMY;
```

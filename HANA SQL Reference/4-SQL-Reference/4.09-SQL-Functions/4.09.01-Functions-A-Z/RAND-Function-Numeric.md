# 4.9.1.150 RAND Function (Numeric)

> [↑ 4.9.1 Alphabetical List Of Functions](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 282–283

Returns a pseudo-random DOUBLE value.

## Syntax

```sql
RAND()
```

## Description

Returns a pseudo-random DOUBLE value in the range of 0 to less than 1.0.

Values generated by the RAND function are not safe for cryptographic or security purposes. Use the RAND_SECURE function for values that are safe for cryptographic or security purposes.

## Example

The following example returns a pseudo-random DOUBLE value similar to `0.4610119133779396`:

```sql
SELECT RAND() FROM DUMMY;
```

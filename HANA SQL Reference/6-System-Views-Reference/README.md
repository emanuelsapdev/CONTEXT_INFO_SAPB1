# 6 System Views Reference

> Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, página 1399

SAP HANA includes system views, monitoring views, and embedded statistics service views.

[System Views](6.01-System-Views/README.md)

System views allow you to query for various information about the system state using SQL commands. The results appear as tables.

[Monitoring Views](6.02-Monitoring-Views/README.md)

SAP HANA includes a set of runtime views called monitoring views that provide actual SAP HANA runtime data, including statistics and status information related to the execution of DML statements. These views are useful for monitoring and troubleshooting performance. The data in monitoring views is not stored on disk; it is calculated when you execute a query on one of the views.

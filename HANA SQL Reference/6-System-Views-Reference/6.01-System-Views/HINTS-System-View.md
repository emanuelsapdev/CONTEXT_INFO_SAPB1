# 6.1.87 HINTS System View

> [↑ 6.1 System Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, página 1506

Provides all available hints to be used in WITH HINT clauses.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| HINT_NAME | VARCHAR(45) | Displays the hint name that can be used inside the WITH HINT() syntax. |
| DESCRIPTION | VARCHAR(5000) | Displays a description of the hint. |

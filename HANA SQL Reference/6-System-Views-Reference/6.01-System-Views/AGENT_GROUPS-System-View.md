# 6.1.14 AGENT_GROUPS System View

> [↑ 6.1 System Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, página 1413

Lists active data provisioning agent groups in the system.

## Structure

| **Column** | **Data type** | **Description** |
| --- | --- | --- |
| AGENT_GROUP_NAME | NVARCHAR(256) | Displays the name of the agent group. |

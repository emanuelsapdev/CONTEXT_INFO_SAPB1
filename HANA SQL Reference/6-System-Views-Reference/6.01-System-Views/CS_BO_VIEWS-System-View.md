# 6.1.44 CS_BO_VIEWS System View

> [↑ 6.1 System Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1448–1449

Provides information about business object views for column store join views.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| SCHEMA_NAME | NVARCHAR(256) | Displays the schema name. |
| VIEW_NAME | NVARCHAR(256) | Displays the join view name. |
| BO_VIEW_NAME | NVARCHAR(256) | Displays the business object view name. |
| ANCHOR_SCHEMA_NAME | NVARCHAR(256) | Displays the anchor schema name. |
| ANCHOR_TABLE_NAME | NVARCHAR(256) | Displays the anchor table name. |

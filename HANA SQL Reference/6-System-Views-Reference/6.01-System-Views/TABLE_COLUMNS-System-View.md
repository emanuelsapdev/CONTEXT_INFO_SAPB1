# 6.1.161 TABLE_COLUMNS System View

> [↑ 6.1 System Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1585–1589

Provides information about available table columns.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| SCHEMA_NAME | NVARCHAR(256) | Displays the schema name. |
| TABLE_NAME | NVARCHAR(256) | Displays the table name. |
| TABLE_OID | BIGINT | Displays the object ID of the table. |
| COLUMN_NAME | NVARCHAR(256) | Displays the name of the column. |
| POSITION | INTEGER | Indicates the ordinal position of the column in a record. |
| DATA_TYPE_ID | SMALLINT | Displays the SQL data type ID of the column. |
| DATA_TYPE_NAME | VARCHAR(16) | Displays the SQL data type name of the column. |
| OFFSET | SMALLINT | Displays the offset of the column in the record. |
| LENGTH | INTEGER | Indicates the number of chars for CHAR types, number of max digits for numeric types, number of chars for date time types, and number of bytes for LOB types. |
| SCALE | INTEGER | Indicates the numeric types: the maximum number of digits to the right of the decimal point; time, timestamp: the decimal digits are defined as the number of digits to the right of the decimal point in the second's component of the data. |
| IS_NULLABLE | VARCHAR(5) | Displays whether the column is allowed to accept null values: TRUE or FALSE. |
| DEFAULT_VALUE | NVARCHAR(5000) | Displays the default value of the column. |
| COLLATION | NVARCHAR(256) | Displays the collation used for this column. |
| COMMENTS | NVARCHAR(5000) | Displays the description for this column. |
| MAX_VALUE | VARCHAR(1) | Deprecated: no longer set. |
| MIN_VALUE | VARCHAR(1) | Deprecated: no longer set. |
| CS_DATA_TYPE_ID | INTEGER | Displays the column store data type ID. |
| CS_DATA_TYPE_NAME | VARCHAR(16) | Displays the column store data type name. |
| DDIC_DATA_TYPE_ID | INTEGER | Displays the DDIC data type ID. |
| DDIC_DATA_TYPE_NAME | VARCHAR(7) | Displays the DDIC data type name. |
| COMPRESSION_TYPE | VARCHAR(9) | Indicates the type of compression: DE FAULT, PREFIXED, SPARSE, CLUS TERED, SPARSE, CLUSTERED, INDI RECT, RLE, and LINEAR RLE. The default value for the column is shown. The actual value can be checked in the system view M_CS_COLUMNS. For row store columns, NONE is shown. |
| INDEX_TYPE | VARCHAR(4) | Indicates the type of index: NONE or FULL. |
| COLUMN_ID | BIGINT | Displays the ID of the column. |
| PRELOAD | VARCHAR(5) | Displays if the column is preloaded: TRUE or FALSE. Preload information can be NULL in case of row store, virtual columns, or tables on extended storage. |
| GENERATED_ALWAYS_AS | NVARCHAR(1000) | Displays the expression of the column created by GENERATED... AS. |
| HAS_SCHEMA_FLEXIBILITY | VARCHAR(5) | Displays if the column has schema flexibility: TRUE or FALSE. |
| FUZZY_SEARCH_INDEX | VARCHAR(5) | Displays if the column has a fuzzy search index: TRUE or FALSE. |
| FUZZY_SEARCH_MODE | VARCHAR(16) | Displays the fuzzy search mode. |
| MEMORY_THRESHOLD | INTEGER | Displays the memory threshold in bytes for LOB types. |
| LOAD_UNIT | VARCHAR(7) | Displays the unit of column data loading: TABLE, COLUMN, PAGE, or DE FAULT. |
| GENERATION_TYPE | VARCHAR(22) | Displays ALWAYS AS if the column is generation column, ALWAYS AS IDEN TITY, BY DEFAULT AS IDENTITY if the column is an identity column whose values are always generated or generated by default, and NULL otherwise.<br>For system-versioning columns, the value 'ALWAYS AS ROW START' indicates a column that was defined as GENERATED ALWAYS AS ROW START, while the value 'ALWAYS AS ROW END' indicates a column that was defined as GENERATED ALWAYS AS ROW END. |
| IS_CACHABLE | VARCHAR(5) | Displays whether the column is part of cached data: TRUE or FALSE. |
| IS_CACHE_KEY | VARCHAR(5) | Displays whether the column is part of cache key: TRUE or FALSE. |
| ROW_ORDER_POSITION | SMALLINT | Displays the row order position. |
| IS_HIDDEN | VARCHAR(5) | Displays whether the column is hidden: TRUE or FALSE. |
| IS_MASKED | VARCHAR(5) | Displays whether the column is masked: TRUE or FALSE. |
| MASK_EXPRESSION | NVARCHAR(5000) | Displays the mask expression. It is only visible to users with the DATA ADMIN and CATALOG READ privileges, the SE LECT METADATA privilege on the schema, and who are the owner of the table or schema. |
| CLIENTSIDE_ENCRYPTION_STATUS | VARCHAR(16) | Displays whether the column is under going encryption (ENCRYPTING), decryption (DECRYPTING), re-encryption with a different column encryption key (REENCRYPTING), re-encryption with the latest version of the existing column encryption key (ACTIVATING), is already encrypted (ENCRYPTED), or is in clear-text (NULL). |
| CLIENTSIDE_ENCRYPTION_COLUMN_KEY_ID | VARCHAR(32) | Displays the UUID of the column encryption key used to encrypt the column. The value is NULL if the column is not encrypted. |
| CLIENTSIDE_ENCRYPTION_MODE | VARCHAR(16) | Displays the encryption mode. Possible values are RANDOM, DETERMINISTIC, or NULL (not encrypted). |
| PERSISTENT_MEMORY | VARCHAR(5) | Displays the userspecified persistent memory preference: TRUE (persistent memory is ON), or FALSE (persistent memory OFF). If the user has not speci fied a persistent memory preference, or if the preference is set to the default, then the value is NULL. |
| NUMA_NODE_INDEXES | VARCHAR (1024) | Displays a comma-separated list of userspecified logical NUMA node indexes for the table columns. For each column entry in this view there will be preferences (if set); otherwise, the value is NULL.<br>The elements of the list are either individual nodes indexes or ranges of index nodes, or a mixture of both. For example, the value `0, 1 TO 3, 6` indicates node indexes 0, 1, 2, 3, and 6. |

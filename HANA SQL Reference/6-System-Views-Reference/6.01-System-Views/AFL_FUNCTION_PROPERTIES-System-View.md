# 6.1.9 AFL_FUNCTION_PROPERTIES System View

> [↑ 6.1 System Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1409–1410

Provides information about available AFL function properties.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| SCHEMA_NAME | NVARCHAR(256) | Displays the schema of the AFL function properties. |
| AREA_NAME | NVARCHAR(256) | Displays the area name of the AFL function properties. |
| FUNCTION_NAME | NVARCHAR(256) | Displays the function name of the AFL function properties. |
| KEY | NVARCHAR(256) | Displays the key of the AFL function properties. |
| VALUE | NVARCHAR(1024) | Displays the value of the AFL function properties. |

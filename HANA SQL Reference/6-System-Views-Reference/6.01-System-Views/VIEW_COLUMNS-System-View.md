# 6.1.181 VIEW_COLUMNS System View

> [↑ 6.1 System Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1614–1617

Lists available view columns.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| SCHEMA_NAME | NVARCHAR(256) | Displays the schema name. |
| VIEW_NAME | NVARCHAR(256) | Displays the view name. |
| VIEW_OID | BIGINT | Displays the object ID of the view. |
| COLUMN_NAME | NVARCHAR(256) | Displays the view column name. |
| POSITION | INTEGER | Displays the ordinal position of the view column. |
| DATA_TYPE_ID | SMALLINT | Displays the data type ID. |
| DATA_TYPE_NAME | VARCHAR(16) | Displays the data type name. |
| OFFSET | SMALLINT | Displays the offset of the column in a record. |
| LENGTH | INTEGER | Displays the number of chars for character types; max number of digits for numeric types; number of chars for datetime types; and number of bytes for LOB types. |
| SCALE | INTEGER | Numeric types: Displays the maximum number of digits to the right of the decimal point.<br>Time, TIMESTAMP: defines the decimal digits as the number of digits to the right of the decimal point in the seconds component of the data. |
| IS_NULLABLE | VARCHAR(5) | Displays whether the column is allowed to accept a NULL value: TRUE/FALSE. |
| DEFAULT_VALUE | NVARCHAR(5000) | Displays the default value. |
| COLLATION | NVARCHAR(256) | Displays the collation. |
| COMMENTS | NVARCHAR(5000) | Displays the description for this column. |
| MAX_VALUE | VARCHAR(1) | Deprecated. |
| MIN_VALUE | VARCHAR(1) | Deprecated. |
| CS_DATA_TYPE_ID | INTEGER | Displays the column store data type ID. |
| CS_DATA_TYPE_NAME | VARCHAR(16) | Displays the column store data type name. |

| DDIC_DATA_TYPE_ID | INTEGER |
| --- | --- |

Displays the DDIC data type ID.

| DDIC_DATA_TYPE_NAME | VARCHAR(7) | Displays the DDIC data type name. |
| --- | --- | --- |
| COMPRESSION_TYPE | VARCHAR(9) | Displays the type of compression: NONE, DEFAULT, PREFIXED, SPARSE, CLUSTERED, INDIRECT or RLE. |
| INDEX_TYPE | VARCHAR(4) | Displays the type of index: NONE/ FULL. |
| COLUMN_ID | BIGINT | Displays the ID of the column. |
| PRELOAD | VARCHAR(5) | Displays if the column is preloaded: TRUE/FALSE. |
| GENERATED_ALWAYS_AS | NVARCHAR(1000) | Displays the expression of the column created by GENERATED... AS. |
| HAS_SCHEMA_FLEXIBILITY | VARCHAR(5) | Displays if column has schema flexibility: TRUE/FALSE. |
| FUZZY_SEARCH_INDEX | VARCHAR(5) | Displays if the column has a fuzzy search index: TRUE/FALSE. |
| FUZZY_SEARCH_MODE | VARCHAR(16) | Displays the fuzzy search mode. |
| MEMORY_THRESHOLD | INTEGER | Displays the memory threshold in bytes for LOB types. |

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| LOAD_UNIT | VARCHAR(1) | Displays the unit of column data loading: TABLE, COLUMN, or PAGE. |
| GENERATION_TYPE | VARCHAR(1) | Displays ALWAYS AS if the column is a generated column, ALWAYS AS IDEN TITY or BY DEFAULT AS IDENTITY if the column is an identity column whose values are always generated or generated by default, and NULL otherwise |
| IS_CACHABLE | VARCHAR(5) | Displays whether the column is part of cached data: TRUE/FALSE |
| IS_CACHE_KEY | VARCHAR(5) | Displays whether the column is part of the cache key: TRUE/FALSE |
| ROW_ORDER_POSITION | VARCHAR(1) | Displays the row order position |
| IS_HIDDEN | VARCHAR(5) | Displays whether the specified column is hidden: TRUE/FALSE. |
| IS_MASKED | VARCHAR(5) | Displays whether the column is masked: TRUE/FALSE |
| MASK_EXPRESSION | NVARCHAR(5000) | Displays the mask expression (only visible to users with the CATALOG READ, DATA ADMIN, or the SELECT META DATA privilege on the schema, or who own the view or schema). |
| CLIENTSIDE_ENCRYPTION_STATUS | VARCHAR(16) | Displays whether the column is encrypted (ENCRYPTED) or is in cleartext (NULL). |
| CLIENTSIDE_ENCRYPTION_COLUMN_KEY_ID | VARCHAR(32) | Displays the UUID of the column encryption key used to encrypt the column. The value is NULL if the column is not encrypted. |
| CLIENTSIDE_ENCRYPTION_MODE | VARCHAR(16) | Displays the encryption mode. Possible values are RANDOM, DETERMINISTIC, or NULL (not encrypted). |
| PERSISTENT_MEMORY | VARCHAR(1) | Not applicable. |
| NUMA_NODE_INDEXES | VARCHAR(1) | Displays the comma-separated list of ranges of userspecified logical NUMA node indexes. |

# 6.1.43 CS_ALL_COLUMNS System View

> [↑ 6.1 System Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1446–1448

Provides information from all columns of column tables, including internal ones.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| SCHEMA_NAME | NVARCHAR(256) | Displays the schema name. |
| TABLE_NAME | NVARCHAR(256) | Displays the table name. |
| COLUMN_NAME | NVARCHAR(256) | Displays the available table columns. |
| POSITION | INTEGER | Displays the ordinal position of the parameter. |
| GENERATION_TYPE | VARCHAR(22) | Displays the generation type of the column. ALWAYS AS appears if the column is a generation column. ALWAYS AS IDENTITY or BY DEFAULT AS IDENTITY appears if the column is an identity column whose values are always generated or generated by default. If the column is neither generation nor identify, NULL appears. |
| GENERATED_ALWAYS_AS | NVARCHAR(1000) | Displays the expression of the column created by GENERATED ALWAYS AS. |
| INTERNAL_ATTRIBUTE_TYPE | VARCHAR(32) | Displays the attribute type for internal columns, otherwise NULL. |
| INTERNAL_COLUMN_ID | BIGINT | Displays the ID of the internal column. |

# 6.1.198 XSA_AUDIT_LOG System View

> [↑ 6.1 System Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1633–1635

Provides information about XSA audit records. Database users with the AUDIT ADMIN, AUDIT OPERATOR, or AUDIT READ system privilege can view information in this system view. For all other database users, this view is empty.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| TIMESTAMP | TIMESTAMP | Displays the time that the event occurred. |
| HOST | VARCHAR(64) | Displays the name of the host where the event occurred. |
| PORT | INTEGER | Displays the port number. |
| SERVICE_NAME | VARCHAR(32) | Displays the name of the service. |
| CONNECTION_ID | INTEGER | Displays the connection ID. |
| CLIENT_HOST | NVARCHAR(256) | Displays the IP of the client host. |
| CLIENT_IP | VARCHAR(45) | Displays the IP of the client application. |
| CLIENT_PID | BIGINT | Displays the PID of the client process. |
| CLIENT_PORT | INTEGER | Displays the port of the client process. |
| USER_NAME | NVARCHAR(256) | Displays the name of the user that is connected to the database. |
| STATEMENT_USER_NAME | NVARCHAR(256) | Displays the name of the user who executed the statement. |
| APPLICATION_NAME | NVARCHAR(256) | Displays the name of the application. |
| APPLICATION_USER_NAME | NVARCHAR(256) | Displays the name of the application user. |
| AUDIT_POLICY_NAME | NVARCHAR(256) | Displays the name of the Audit Policy hit. |
| EVENT_STATUS | VARCHAR(32) | Displays whether the event was successful or not. |
| EVENT_LEVEL | VARCHAR(16) | Displays the severity level of the event. |
| EVENT_ACTION | VARCHAR(64) | Displays the action performed by the audit event. |
| KEY | NVARCHAR(2000) | Displays the attribute that was changed. |
| PREV_VALUE | NVARCHAR(5000) | Displays the old value of the attribute. |
| VALUE | NVARCHAR(5000) | Displays the new value of the attribute. |
| STATEMENT_STRING | NCLOB | Displays the SQL statement that caused the event. |

| COMMENT | VARCHAR(5000) |
| --- | --- |

Displays extra information about the event.

| CREATE_TIME | TIMESTAMP | Displays the time of the event occurrence at the client side. |
| --- | --- | --- |
| XSA_MESSAGE_IP | VARCHAR(45) | Displays the PI address of the event occurrence. |
| XSA_TENANT | VARCHAR(36) | Displays the XSA tenant GUID. |
| XSA_UUID | VARCHAR(256) | Displays the unique audit log message ID generated by the audit service. |
| XSA_CHANNEL | VARCHAR(16) | Displays the communication protocol that was used when the audit event was triggered. |
| XSA_ATTACHMENT_ID | NVARCHAR(256) | Displays the ID of the attachment that triggered the event. |
| XSA_ATTACHMENT_NAME | NVARCHAR(256) | Displays the name of the attachment that triggered the event. |
| XSA_ORGANIZATION_ID | VARCHAR(36) | Displays the application organization GUID. |

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| XSA_SPACE_ID | VARCHAR(36) | Displays the application space GUID. |
| XSA_INSTANCE_ID | VARCHAR(36) | Displays the GUID of the used auditlog service instance. |
| XSA_BINDING_ID | VARCHAR(36) | Displays the application binding GUID in regards to the specific auditlog service instance that is being used. |
| XSA_OBJECT | NVARCHAR(5000) | Displays the object containing the accessed personal data. |
| XSA_DATA_SUBJECT | NVARCHAR(5000) | Displays the owner of the accessed personal data. |

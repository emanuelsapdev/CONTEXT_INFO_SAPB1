# 6.1.13 AGENT_CONFIGURATION System View

> [↑ 6.1 System Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1412–1413

Provides agent configuration information.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| AGENT_NAME | NVARCHAR(256) | Displays the agent name. |
| KEY | VARCHAR(128) | Displays the agent property key. |
| VALUE | NCLOB | Displays the agent property value. |

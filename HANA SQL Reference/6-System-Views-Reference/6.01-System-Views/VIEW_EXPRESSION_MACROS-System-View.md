# 6.1.182 VIEW_EXPRESSION_MACROS System View

> [↑ 6.1 System Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1617–1618

Describes the expression macros defined for views.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| SCHEMA_NAME | NVARCHAR(256) | Displays the schema name for the view. |
| VIEW_NAME | NVARCHAR(256) | Displays the name of the view. |
| EXPRESSION_MACRO_NAME | NVARCHAR(256) | Displays the name of the macro. |
| DEFINITION | NVARCHAR(5000) | Displays the definition (formula) for the macro. |

# 6.1.138 RESERVED_KEYWORDS System View

> [↑ 6.1 System Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1558–1559

Provides a list of reserved keywords that are not allowed to be used as a simple identifier.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| RESERVED_KEYWORD | VARCHAR(256) | Displays the reserved keyword. |

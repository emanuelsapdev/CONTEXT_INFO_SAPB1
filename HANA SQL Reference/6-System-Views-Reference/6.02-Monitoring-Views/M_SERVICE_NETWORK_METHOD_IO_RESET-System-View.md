# 6.2.258 M_SERVICE_NETWORK_METHOD_IO_RESET System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, página 1993

Provides service network method I/O statistics since the last reset.

This view contains values accumulated since the last reset of the main view M_SERVICE_NETWORK_METHOD_IO. Refer to M_SERVICE_NETWORK_METHOD_IO for information about the structure and use of this view.

In addition to the members mentioned in M_SERVICE_NETWORK_METHOD_IO, this view also contains a timestamp field, RESET_TIME, which indicates the last time the data was reset.

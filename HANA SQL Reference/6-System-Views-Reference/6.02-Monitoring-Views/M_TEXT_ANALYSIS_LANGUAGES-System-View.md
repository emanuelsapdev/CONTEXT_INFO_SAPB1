# 6.2.331 M_TEXT_ANALYSIS_LANGUAGES System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, página 2109

Provides a list of supported languages.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| LANGUAGE_NAME | VARCHAR(32) | Displays the language name. |
| LANGUAGE_CODE | VARCHAR(2) | Displays the language ISO 639-1 code. |

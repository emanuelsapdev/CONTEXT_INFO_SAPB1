# 6.2.210 M_PLUGIN_MANIFESTS System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1936–1937

Provides information about installed plugins.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| PLUGIN_NAME | VARCHAR(32) | Displays the plugin name. |
| KEY | VARCHAR(64) | Displays the key. |
| VALUE | VARCHAR(256) | Displays the value. |

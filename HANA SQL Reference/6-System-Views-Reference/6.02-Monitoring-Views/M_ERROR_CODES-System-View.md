# 6.2.95 M_ERROR_CODES System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, página 1771

Provides error codes with descriptions.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| CODE | INTEGER | Displays the error code. |
| CODE_STRING | VARCHAR(256) | Displays the error code string. |
| DESCRIPTION | VARCHAR(2000) | Displays the error description. |

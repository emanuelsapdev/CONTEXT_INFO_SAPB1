# 6.2.359 M_WORKLOAD_REPLAY_PREPROCESSES System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 2155–2157

Provides information about preprocesses for captured workloads.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| CAPTURE_ID | BIGINT | Displays the unique ID of the captured workload. |
| CAPTURE_NAME | NVARCHAR (256) | Displays the userspecified name of the captured workload. |
| CAPTURE_DESCRIPTION | NVARCHAR (5000) | Displays the userspecified description of the captured workload. |
| CAPTURE_START_TIME | TIMESTAMP | Displays the start timestamp of the captured workload. |
| CAPTURE_UTC_START_TIME | TIMESTAMP | Displays the UTC start timestamp of the captured workload. |
| CAPTURE_END_TIME | TIMESTAMP | Displays the end timestamp of the captured workload. |
| CAPTURE_UTC_END_TIME | TIMESTAMP | Displays the UTC end timestamp of the captured workload. |
| IS_FILTER_APPLIED | VARCHAR (5) | Displays the flag to be set to 'false' if user specified any non-default value to any filter parameters. |
| CAPTURE_SYSTEM_ID | VARCHAR (3) | Displays the system ID, in which the capture has been done. |
| CAPTURE_DATABASE_NAME | NVARCHAR (256) | Displays the database name, in which the capture has been done. |
| CAPTURE_VERSION | INTEGER | Displays the version number of the structure format of the captured work loads or capturing workload. |
| PREPROCESS_START_TIME | TIMESTAMP | Displays the start timestamp of the pre processing. |
| PREPROCESS_UTC_START_TIME | TIMESTAMP | Displays the UTC start timestamp of the preprocessing. |
| PREPROCESS_END_TIME | TIMESTAMP | Displays the end timestamp of the pre processing. |
| PREPROCESS_UTC_END_TIME | TIMESTAMP | Displays the UTC end timestamp of the preprocessing. |
| PREPROCESS_VERSION | INTEGER | Displays the version number of the structure format of the preprocessed workloads or preprocessing workload. |
| STATUS | VARCHAR (16) | Displays the status of workload preprocess. |
| PROGRESS | DOUBLE | Displays the current progress of preprocess. |
| LEVEL | VARCHAR (16) | Displays the level of workload captures. |
| PARAMETERS | NCLOB | Displays the applied parameter's key/ value pairs. |
| STATEMENT_DURATION_THRESHOLD | BIGINT | Displays the threshold value for the elapsed time of executed statements to be captured. |
| FLUSH_INTERVAL | INTEGER | Displays the interval of flushing out the file output stream. |
| CAPTURE_SESSION_COUNT | BIGINT | Displays the number of current or captured logical sessions. |
| CAPTURE_STATEMENT_COUNT | BIGINT | Displays the number of current or captured statements. |
| CAPTURE_FETCH_COUNT | BIGINT | Displays the number current or captured fetch operations. |
| CAPTURE_COMMITTED_TRANSACTION_COUNT | BIGINT | Displays the number of current or captured committed transactions. |
| CAPTURE_FAILED_STATEMENT_COUNT | BIGINT | Displays the number of failed capture statements. |
| CAPTURE_FAILED_FETCH_COUNT | BIGINT | Displays the number of failed fetch operations during capture. |
| CAPTURE_SIZE | BIGINT | Displays the size of captured workload file in bytes. |
| PREPROCESS_SIZE | BIGINT | Displays the total amounts of file sizes generated by workload preprocess in bytes. |
| ERROR_CODE | INTEGER | Displays the error code generated by system during capturing. |
| ERROR_MESSAGE | NVARCHAR (5000) | Displays the error message generated by system during capturing. |

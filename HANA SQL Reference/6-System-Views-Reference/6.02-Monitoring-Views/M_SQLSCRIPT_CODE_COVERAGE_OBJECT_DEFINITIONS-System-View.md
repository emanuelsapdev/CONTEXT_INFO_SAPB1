# 6.2.269 M_SQLSCRIPT_CODE_COVERAGE_OBJECT_DEFINITIONS System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 2010–2011

Provides definitions for the objects referenced in SQLScript code coverage results.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| OBJECT_DEFINITION_ID | BIGINT | Displays the ID of the object definition. |
| OBJECT_DEFINITION | NCLOB | Displays the definition of the object. |

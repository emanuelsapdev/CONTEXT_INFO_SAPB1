# 6.2.264 M_SERVICE_TRACES System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 2006–2007

Provides configured trace components for each service type.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| SERVICE_NAME | VARCHAR(32) | Displays the service name. |
| COMPONENT_NAME | VARCHAR(32) | Displays the trace component name. |

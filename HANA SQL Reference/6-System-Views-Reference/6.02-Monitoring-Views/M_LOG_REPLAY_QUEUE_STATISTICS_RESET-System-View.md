# 6.2.169 M_LOG_REPLAY_QUEUE_STATISTICS_RESET System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1886–1887

Provides information about log replay queue statistics.

This view contains values accumulated since the last reset of the main view M_LOG_REPLAY_QUEUE_STATISTICS. Refer to M_LOG_REPLAY_QUEUE_STATISTICS for information about the structure and use of this view.

In addition to the members mentioned in M_LOG_REPLAY_QUEUE_STATISTICS, this view also contains a timestamp field, RESET_TIME, which indicates the last time the data was reset.

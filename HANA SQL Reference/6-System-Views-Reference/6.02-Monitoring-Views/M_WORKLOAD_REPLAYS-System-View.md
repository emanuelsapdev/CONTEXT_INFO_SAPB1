# 6.2.358 M_WORKLOAD_REPLAYS System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 2153–2155

Provides information about workload replays.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| CAPTURE_ID | BIGINT | Displays the unique ID of the captured workload. |
| CAPTURE_SYSTEM_ID | VARCHAR(3) | Displays the system ID in which the capture has been done. |
| CAPTURE_DATABASE_NAME | NVARCHAR(256) | Displays the name of the database in which the capture has been done. |
| REPLAY_ID | BIGINT | Displays the unique ID of the replayed workload. |
| REPLAY_NAME | NVARCHAR(256) | Displays the userspecified name of the replayed workload. |
| REPLAY_DESCRIPTION | NVARCHAR(5000) | Displays the userspecified description of the replayed workload. |
| REPLAY_START_TIME | TIMESTAMP | Displays the start timestamp of the replay. |
| REPLAY_UTC_START_TIME | TIMESTAMP | Displays the UTC start timestamp of the replay. |
| REPLAY_END_TIME | TIMESTAMP | Displays the end timestamp of the replayed workload. |
| REPLAY_UTC_END_TIME | TIMESTAMP | Displays the UTC end timestamp of the replayed workload. |
| REPLAY_HOST | VARCHAR (64) | Displays the host name in which the replay has been done. |
| REPLAY_PORT | INTEGER | Displays the service port number in which the replay has been done. |
| REPLAY_SYSTEM_ID | VARCHAR(3) | Displays the system ID in which the replay has been done. |
| REPLAY_DATABASE_NAME | NVARCHAR(256) | Displays the name of the database in which the replay has been done. |
| STATUS | VARCHAR(16) | Displays the status of workload replays. |
| PROGRESS | DOUBLE | Displays a measure of how much the re player has made its progress. |
| REPLAY_SESSION_COUNT | BIGINT | Displays the number of current or replayed logical sessions. |
| REPLAY_STATEMENT_COUNT | BIGINT | Displays the number of current or replayed statements. |
| REPLAY_FETCH_COUNT | BIGINT | Displays the number of current or replayed fetch operations. |
| REPLAY_COMMITTED_TRANSACTION_COUNT | BIGINT | Displays the number of current or replayed committed transactions. |
| ERROR_CODE | INTEGER | Displays the error code generated by the system during capturing. |
| ERROR_MESSAGE | NVARCHAR (5000) | Displays the error message generated by the system during capturing. |

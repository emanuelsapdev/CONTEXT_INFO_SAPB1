# 6.2.272 M_SQLSCRIPT_PLAN_PROFILER_RESULTS System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 2014–2017

Stores the results generated by the SQLScript plan profiler.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| PROCEDURE_HOST | VARCHAR(64) | Displays the name of host where the outermost procedure started. |
| PROCEDURE_PORT | INTEGER | Displays the name of port where the outermost procedure started. |
| PROCEDURE_CONNECTION_ID | INTEGER | Displays the connection ID that started this outermost procedure. |
| PROCEDURE_DATABASE_NAME | NVARCHAR(256) | Displays the database name of outer most procedure. |
| PROCEDURE_SCHEMA_NAME | NVARCHAR(256) | Displays the name of schema of the outermost procedure. |
| PROCEDURE_LIBRARY_NAME | NVARCHAR(256) | Displays the library name of the outer most procedure. |
| PROCEDURE_NAME | NVARCHAR(256) | Displays the name of the outermost procedure. |
| RESULT_ID | INTEGER | Displays the SQLScript profiler ID for the call. |
| OPERATOR | VARCHAR(64) | Displays any predefined operations. |
| OPERATOR_STATEMENT_STRING | NCLOB | Displays the operator string. |
| OPERATOR_DETAILS | NCLOB | Displays any key-value pairs of additional information that only belong to specific operations. |
| START_TIME | TIMESTAMP | Displays the start timestamp of the operation. |
| END_TIME | TIMESTAMP | Displays the end timestamp of the operation. |
| DURATION | BIGINT | Displays the clock time, in microseconds, spent in the operation itself. |
| ACTIVE_TIME_SELF | BIGINT | Displays the clock time, in microseconds, spent in the operation, excluding child operations. |
| ACTIVE_TIME_CUMULATIVE | BIGINT | Displays the clock time, in microseconds, between START_TIME and END_TIME. |
| CPU_TIME_SELF | BIGINT | Displays the CPU time, in microseconds, spent in the operation, excluding child operations. |
| CPU_TIME_CUMULATIVE | BIGINT | Displays the total CPU time, in microseconds, spent in the operation itself and its children |
| USED_MEMORY_SIZE_SELF | BIGINT | Displays the memory used, in bytes, in the operation itself, excluding its children. |
| USED_MEMORY_SIZE_CUMULATIVE | BIGINT | Displays the total memory used, in bytes, in the operation itself, including its children. |
| CONNECTION_ID | INTEGER | Displays the connection ID used for the operation. |
| TRANSACTION_ID | INTEGER | Displays the transaction ID used for the operation. |
| STATEMENT_ID | VARCHAR(20) | Displays the statement ID used for the operation. |
| THREAD_ID | BIGINT | Displays the thread ID used for the operation. |
| OPERATOR_DATABASE_NAME | NVARCHAR(256) | Displays the database name of the procedure/function where the operator is defined. |
| OPERATOR_SCHEMA_NAME | NVARCHAR(256) | Displays the schema name of the procedure/function where the operator is defined. |
| OPERATOR_LIBRARY_NAME | NVARCHAR(256) | Displays the library name of the procedure/function where the operator is defined. |
| OPERATOR_PROCEDURE_NAME | NVARCHAR(256) | Displays the name of the procedure/ function where the operator is defined. |
| OPERATOR_LINE | INTEGER | Displays the SQL line of the operator. |
| OPERATOR_COLUMN | INTEGER | Displays the SQL column of the operator. |
| OPERATOR_POSITION | INTEGER | Displays the SQL position of the operator. |
| OPERATOR_HOST | VARCHAR(64) | Displays the host where the operation occurred. |
| OPERATOR_PORT | INTEGER | Displays the port where the operation occurred. |
| OPERATOR_ID | INTEGER | Displays the ID of the operation. |
| PARENT_OPERATOR_ID | INTEGER | Displays the ID of the parent operation. |

## Permissions

To see all entries in the M_SQLSCRIPT_PLAN_PROFILER_RESULTS system view, you must have the CATALOG READ or OPTIMIZER ADMIN system privilege.

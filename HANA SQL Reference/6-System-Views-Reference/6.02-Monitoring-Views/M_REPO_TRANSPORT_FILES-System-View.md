# 6.2.236 M_REPO_TRANSPORT_FILES System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, página 1965

Provides information about all repository transport files.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| HOST | VARCHAR(64) | Displays the host name. |
| FILE_NAME | VARCHAR(256) | Displays the file name. |
| FILE_SIZE | BIGINT | Displays the file size in bytes. |
| FILE_MTIME | TIMESTAMP | Displays the file date. |

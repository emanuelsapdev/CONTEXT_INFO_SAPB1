# 6.2.43 M_CONDITIONAL_VARIABLES_RESET System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1684–1685

Semaphore statistics (since last reset) .

This view contains values accumulated since the last reset of the main view M_CONDITIONAL_VARIABLES. Refer to M_CONDITIONAL_VARIABLES for information about the structure and use of this view. In addition to the members mentioned in M_CONDITIONAL_VARIABLES, this view also contains a timestamp field RESET_TIME, which indicates the last time the data was reset.

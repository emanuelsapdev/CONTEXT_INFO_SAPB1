# 6.2.2 M_ABSTRACT_SQL_PLAN_STATISTICS System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1637–1639

Provides SQL query runtime statistics.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| HOST | VARCHAR(64) | Displays the host name. |
| PORT | INTEGER | Displays the port number. |
| ABSTRACT_SQL_PLAN_ID | BIGINT | Displays the ID of the abstract SQL plan. |
| PLAN_ID | BIGINT | Displays the logical plan ID as a non-negative value. |
| PREPARATION_TIME | BIGINT | Displays the preparation time. |
| MIN_EXECUTION_TIME_USING_ABSTRACT_SQL_PLAN | BIGINT | Displays the minimum execution time of the plans generated with abstract SQL plans. |
| MAX_EXECUTION_TIME_USING_ABSTRACT_SQL_PLAN | BIGINT | Displays the maximum execution time of the plans generated with abstract SQL plans. |
| AVG_EXECUTION_TIME_USING_ABSTRACT_SQL_PLAN | BIGINT | Displays the average execution time of the plans generated with abstract SQL plans. |
| TOTAL_EXECUTION_COUNT_USING_ABSTRACT_SQL_PLAN | BIGINT | Displays the total number of executions of the plans generated with abstract SQL plans. |
| MIN_EXECUTION_TIME_NOT_USING_ABSTRACT_SQL_PLAN | BIGINT | Displays the minimum execution time of the plans generated by the current optimizer. |
| MAX_EXECUTION_TIME_NOT_USING_ABSTRACT_SQL_PLAN | BIGINT | Displays the maximum execution time of the plans generated by the current optimizer. |
| AVG_EXECUTION_TIME_NOT_USING_ABSTRACT_SQL_PLAN | BIGINT | Displays the average execution time of the plans generated by the current optimizer. |
| TOTAL_EXECUTION_COUNT_NOT_USING_ABSTRACT_SQL_PLAN | BIGINT | Displays the total number of executions of the plans generated by the current optimizer. |
| LAST_EXECUTION_TIMESTAMP_USING_ABSTRACT_SQL_PLAN | TIMESTAMP | Displays the statistics update time for the plans generated with abstract SQL plans. |
| LAST_EXECUTION_TIMESTAMP_NOT_USING_ABSTRACT_SQL_PLAN | TIMESTAMP | Displays the statistics update time for the plans generated by the current optimizer. |

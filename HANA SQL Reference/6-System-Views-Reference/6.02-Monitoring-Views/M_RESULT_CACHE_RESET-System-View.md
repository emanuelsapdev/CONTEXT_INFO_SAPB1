# 6.2.239 M_RESULT_CACHE_RESET System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1967–1968

Provides information about result cache statistics.

This view contains values accumulated since the last reset of the main view M_RESULT_CACHE. Refer to M_RESULT_CACHE for information about the structure and use of this view.

In addition to the members mentioned in M_RESULT_CACHE, this view also contains a timestamp field, RESET_TIME, which indicates the last time the data was reset.

# 6.2.174 M_MEMORY_OBJECTS_RESET System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 1893–1894

Provides values accumulated since the last reset of the main view M_MEMORY_OBJECTS.

In addition to the members mentioned in M_MEMORY_OBJECTS, this view also contains a timestamp field, RESET_TIME, which indicates the last time the data was reset.

Refer to M_MEMORY_OBJECTS for information about the structure and use of this view.

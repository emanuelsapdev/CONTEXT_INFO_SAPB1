# 6.2.361 M_XS_APPLICATION_ISSUES System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 2158–2159

Lists issues related to applications in SAP HANA XS.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| APPLICATION_NAME | NVARCHAR(256) | Displays the name of the application. |
| ERROR_MESSAGE | VARCHAR(1024) | Displays the textual description of the issue. |

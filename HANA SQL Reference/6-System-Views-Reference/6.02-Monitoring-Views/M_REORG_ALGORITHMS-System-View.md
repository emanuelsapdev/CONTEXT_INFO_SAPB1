# 6.2.234 M_REORG_ALGORITHMS System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, página 1964

Provides information about landscape redistribution algorithms.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| ALGORITHM_ID | INTEGER | Displays the ID of the algorithm. |
| DESCRIPTION | VARCHAR(256) | Displays the description. |
| PARAMETERS | VARCHAR(256) | Displays any optional parameters. |

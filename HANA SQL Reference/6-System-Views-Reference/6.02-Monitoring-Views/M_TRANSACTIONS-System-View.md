# 6.2.339 M_TRANSACTIONS System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 2116–2119

Provides information about all transactions created by users or the database.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| HOST | VARCHAR(64) | Displays the host name. |
| PORT | INTEGER | Displays the internal port number. |
| CONNECTION_ID | INTEGER | Displays the connection ID. |
| TRANSACTION_ID | INTEGER | Displays the transaction object ID (this number is reused after a transaction is closed). |
| VOLUME_ID | INTEGER | Displays the volume ID where the trans action has started. |
| PRIMARY_TRANSACTION_ID | INTEGER | Displays the primary transaction object ID for the external transaction. |
| TRANSACTION_SEQUENCE | INTEGER | Displays the transaction sequence number in a transaction. |
| UPDATE_TRANSACTION_ID | BIGINT | Displays the write transaction ID (this number is ever increasing). |
| TRANSACTION_STATUS | VARCHAR(128) | Displays the transaction status; INAC TIVE, ACTIVE, PRECOMMITTED, ABORTING, PARTIAL_ABORTING, or ACTIVE_PREPARE_COMMIT. |
| TRANSACTION_TYPE | VARCHAR(128) | Displays the transaction type; USER, VERSION GARBAGE COLLECTION, DDL VERSION GARBAGE COLLECTION, IN TERNAL, or EXTERNAL. |
| START_TIME | TIMESTAMP | Displays the transaction start time. |
| END_TIME | TIMESTAMP | Displays the transaction end time. |
| START_MVCC_TIMESTAMP | BIGINT | Displays the internal MVCC timestamp of the transaction start time. |
| END_MVCC_TIMESTAMP | BIGINT | Displays the internal MVCC timestamp of the transaction end time. |
| EXECUTED_STATEMENT_COUNT | INTEGER | Displays the number of executed statements in the transaction. |
| CREATED_VERSION_COUNT | INTEGER | Displays the number of created versions in the transaction. |
| ALLOCATED_VERSION_SIZE | BIGINT | Displays the allocated version size in the transaction in bytes. |
| ACQUIRED_LOCK_COUNT | INTEGER | Displays the number of acquired locks in the transaction. |
| LOCK_WAIT_COUNT | INTEGER | Displays the number of lock waits in the transaction. |
| LOCK_WAIT_TIME | DOUBLE | Displays the accumulated lock wait time in the transaction in seconds. |
| LOCK_WAIT_TIMEOUT | INTEGER | Displays the number of milliseconds a statement waits for a lock to be released . |
| LOG_SIZE | BIGINT | Displays the generated log amount in the transaction in byptes. |
| CURRENT_STATEMENT_ID | VARCHAR(256) | Displays the current statement ID. |
| CURRENT_STATEMENT_SEQUENCE | INTEGER | Displays the sequence number of the currently executed statement. |
| ALLOCATED_MEMORY_SIZE | BIGINT | Displays the memory size occupied by the transaction in bytes. |
| ACQUIRED_METALOCK_INDEX | INTEGER | Displays the index of the acquired metalock. |
| LOG_PARTITION_ID | SMALLINT | Displays the log partition ID of the transaction. |
| REDO_LOG_AMOUNT | BIGINT | Displays the size of the redo log amount generated by the transaction in bytes. |
| UNDO_LOG_AMOUNT | BIGINT | Displays the size of the undo log amount generated by the transaction in bytes. |
| MIN_MVCC_SNAPSHOT_TIMESTAMP | BIGINT | Displays the logical timestamp of the first executed statement in the transaction. |
| LAST_COMMIT_ID | BIGINT | Displays the last commit ID of the transaction. |
| ACTIVE_STATEMENT_COUNT | INTEGER | Displays the number of opened cursors in the transaction. |
| ISOLATION_LEVEL | VARCHAR(128) | Displays the isolation level of each transaction: READ UNCOMMITTED, READ COMMITTED, REPEATABLE READ, or SERIALIZABLE. |
| LOG_FLUSH_ENABLED | VARCHAR(5) | Displays whether log flushing is enabled for the transaction (TRUE/FALSE). |
| LOGGING_ENABLED | VARCHAR(5) | Displays whether logging is enabled for the transaction (TRUE/FALSE). |

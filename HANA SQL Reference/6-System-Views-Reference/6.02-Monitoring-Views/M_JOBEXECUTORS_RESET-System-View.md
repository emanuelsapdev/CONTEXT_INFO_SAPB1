# 6.2.137 M_JOBEXECUTORS_RESET System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, página 1832

Provides values accumulated since the last reset of the main view M_JOBEXECUTORS.

In addition to the members mentioned in M_JOBEXECUTORS, this view also contains a timestamp field, RESET_TIME, which indicates the last time the data was reset

Refer to M_JOBEXECUTORS for information about the structure and use of this view.

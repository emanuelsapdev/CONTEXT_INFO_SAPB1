# 6.2.357 M_WORKLOAD_CAPTURES System View

> [↑ 6.2 Monitoring Views](README.md) · Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 2150–2153

Provides information about workload captures.

## Structure

| **Column name** | **Data type** | **Description** |
| --- | --- | --- |
| CAPTURE_ID | BIGINT | Displays the unique ID of the captured workload. |
| CAPTURE_NAME | NVARCHAR (256) | Displays the userspecified name of the captured workload. |
| CAPTURE_DESCRIPTION | NVARCHAR (5000) | Displays the userspecified description of the captured workload. |
| CAPTURE_VERSION | INTEGER | Displays the version number of the structure format for the captured work loads or capturing workload. |
| START_TIME | TIMESTAMP | Displays the start timestamp of the capture. |
| UTC_START_TIME | TIMESTAMP | Displays the UTC start timestamp of the capture. |
| END_TIME | TIMESTAMP | Displays the end timestamp of the captured workload |
| UTC_END_TIME | TIMESTAMP | Displays the UTC end timestamp of the captured workload. |
| IS_FILTER_APPLIED | VARCHAR (5) | Displays the flag that is set to FALSE if the user Displays any non-default value to any filter parameters. |
| SYSTEM_ID | VARCHAR (3) | Displays the system ID in which the capture has been done. |
| DATABASE_NAME | NVARCHAR (256) | Displays the database name in which the capture has been done. |
| STATUS | VARCHAR (16) | Displays the status of the workload captures. |
| IS_LOADED | VARCHAR (5) | Displays the flag that is set to TRUE if the captured data is loaded into the database. |
| PROGRESS | DOUBLE | Displays the current progress of the load. |
| LEVEL | VARCHAR (16) | Displays the level of workload captures. |
| PARAMETERS | NCLOB | Displays the applied parameter's key/ value pairs. |
| STATEMENT_DURATION_THRESHOLD | BIGINT | Displays the threshold value for the workloads to be captured. |
| FLUSH_INTERVAL | INTEGER | Displays the interval of flushing out the file output stream. |
| CAPTURE_FILE_NAME | VARCHAR(256) | Displays the file name of the captured workload. |
| CAPTURE_SESSION_COUNT | BIGINT | Displays the number of current or captured logical sessions. |
| CAPTURE_STATEMENT_COUNT | BIGINT | Displays the number of current or captured statements. |
| CAPTURE_FETCH_COUNT | BIGINT | Displays the number current or captured fetch operations. |
| CAPTURE_COMMITTED_TRANSACTION_COUNT | BIGINT | Displays the number of current or captured committed transactions. |
| CAPTURE_SIZE | BIGINT | Displays the size of the captured work load file. |
| CAPTURE_FAILED_STATEMENT_COUNT | BIGINT | Displays the number of failed current or capture statements. |
| CAPTURE_FAILED_FETCH_COUNT | BIGINT | Displays the number of failed current or capture fetch operations. |
| ERROR_CODE | INTEGER | Displays the error code generated by the system during capturing. |
| ERROR_MESSAGE | NVARCHAR (5000) | Displays the error message generated by system during capturing. |

# 1 SAP HANA SQL Reference Guide for SAP HANA Platform

> Fuente: *SAP HANA SQL Reference Guide for SAP HANA Platform (SAP HANA Platform 2.0)*, páginas 20–21

The SAP HANA SQL Reference describes all SQL data types, predicates, operators, expressions, functions, statements, and error codes. The SAP HANA System Views Reference describes all SYS schema views that allow you to query for various information about the system state using SQL operations.
